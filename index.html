The Structure Resource Library

When I was a medium program, I couldn't find one example of what was realistic for a center my size. Then we grew, and I couldn't find one for large either. Everything was written for a giant chain or nothing at all. And family and group programs almost never see themselves in these resources. So here it is... by program size. Pick your size above and everything filters to you. Look one size up to see where you're going.

5. Systems library

Every working system has five parts: Trigger → Owner → Process → Proof → Follow-up. An SOP sitting in a folder is only the process. Use these as starting points, then make them yours.

6. Accountability toolkit
